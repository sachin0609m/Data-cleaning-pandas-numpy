# Data Cleaning with Python

## Project Overview
This project demonstrates a structured data-cleaning workflow using Python, pandas, and NumPy. It focuses on identifying data-quality issues and preparing a dataset for reliable analysis.

## Objective
Transform a raw dataset into a clean, analysis-ready dataset and document the decisions made during the cleaning process.

## Project Workflow
1. Load and inspect the raw dataset.
2. Create a data-quality report.
3. Check missing values in each column.
4. Check duplicate records.
5. Inspect data types and inconsistent values.
6. Handle missing values using an explained approach.
7. Remove duplicates where appropriate.
8. Correct data types and standardize values where needed.
9. Validate the cleaned dataset.
10. Save the cleaned data for future analysis.

## How to Run
1. Clone this repository.
2. Install the required libraries.
3. Keep the input dataset and notebook in the same folder.
4. Open the notebook in Jupyter and run the cells.

```bash
pip install pandas numpy jupyter
jupyter notebook
```
